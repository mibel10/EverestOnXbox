# EverestOnXbox
# A project to try to port everest mod loader for celeste to Xbox developer mode
EverestOnXbox is a porting project to try and recompile Celeste with Everest + Strawberry jam into a UWP app that can run on Xbox One & Series consoles with dev mode activated
# Status
I Sucessfully adapted the celeste source code and Celeste.dll alongside FNA.dll to work with UWP and got a .appx that builded with 0 errors,however it still doesnt have everest,im currently testing it out to see if the game works properly without everest and if it does,then ill start working on porting everest over
